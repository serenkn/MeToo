# 機能要件一覧 — MeToo

作成日：2026-05-13  
バージョン：1.0

-----

## 1. 認証・ユーザー管理

|ID     |機能              |優先度|備考         |
|-------|----------------|---|-----------|
|AUTH-01|メール・パスワードで新規登録  |必須 |           |
|AUTH-02|メール・パスワードでログイン  |必須 |           |
|AUTH-03|ログアウト           |必須 |           |
|AUTH-04|パスワードリセット（メール送信）|必須 |           |
|AUTH-05|Googleログイン      |任意 |将来対応       |
|AUTH-06|セッション管理         |必須 |NextAuth.js|

-----

## 2. プロフィール

|ID    |機能             |優先度|備考              |
|------|---------------|---|----------------|
|PRO-01|プロフィール作成（初回登録時）|必須 |名前・年齢・属性・ペース・エリア|
|PRO-02|プロフィール編集       |必須 |                |
|PRO-03|アバター画像アップロード   |必須 |R2に保存、URLをDBに格納 |
|PRO-04|他ユーザーのプロフィール閲覧 |必須 |                |
|PRO-05|参加履歴の表示        |任意 |将来対応            |

-----

## 3. 募集（さがす）

|ID    |機能                         |優先度|備考                   |
|------|---------------------------|---|---------------------|
|REC-01|募集一覧表示                     |必須 |新着順デフォルト             |
|REC-02|募集の検索・フィルター                |必須 |エリア・距離・ペース・人数・レベル・日付 |
|REC-03|募集詳細表示                     |必須 |集合場所はGoogleマップへのリンク表示|
|REC-04|募集作成                       |必須 |                     |
|REC-05|募集編集                       |必須 |主催者のみ                |
|REC-06|募集削除                       |必須 |主催者のみ                |
|REC-07|お気に入り（☆）登録・解除              |任意 |                     |
|REC-08|集合場所の表示（住所＋Googleマップで開くリンク）|必須 |地図APIは使わない（docs/06参照）|
|REC-09|募集への参加申請                   |必須 |→ 申請画面へ遷移            |

-----

## 4. 参加申請・グループ

|ID    |機能                      |優先度|備考    |
|------|------------------------|---|------|
|APP-01|参加申請の送信（メッセージ任意・200文字以内）|必須 |      |
|APP-02|主催者への申請通知               |必須 |アプリ内通知|
|APP-03|主催者による申請の承認・拒否          |必須 |      |
|APP-04|参加メンバー一覧の表示             |必須 |      |
|APP-05|参加したグループ一覧の表示           |必須 |      |
|APP-06|グループからの脱退               |任意 |      |

-----

## 5. トーク（はなす）

|ID     |機能                 |優先度|備考                  |
|-------|-------------------|---|--------------------|
|TALK-01|グループチャット（テキスト）     |必須 |参加承認後に開放            |
|TALK-02|トーク一覧表示（最新メッセージ・日時）|必須 |                    |
|TALK-03|未読バッジ表示            |必須 |                    |
|TALK-04|リアルタイム更新           |必須 |Pusherで配信（docs/05参照）|
|TALK-05|画像送信               |任意 |将来対応                |
|TALK-06|スタンプ・リアクション        |任意 |将来対応                |

## 9. MVP（最初のリリース）に絞った機能

以下をMVPスコープとする。

- AUTH-01〜04（認証）
- PRO-01〜04（プロフィール）
- REC-01〜09（募集）
- APP-01〜05（参加申請・グループ）
- TALK-01〜04（トーク）
- NTF-01〜03（アプリ内通知）
- SAF-01・03（通報・規約）
